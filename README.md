# Solana Escrow

Escrow-проект на Solana, написанный с использованием Rust и Anchor.

Проект позволяет двум пользователям безопасно обмениваться SPL-токенами через smart contract без необходимости доверять третьей стороне.

## Идея проекта

Идея проекта появилась из личного опыта.

Когда-то я сам пользовался услугами escrow-сервиса, но это был не smart contract, а обычный человек-посредник, которому обе стороны доверяли активы. За свои услуги он брал комиссию.

Я знаю что подобные контракты уже существуют, но мне стало интересно реализовать похожую логику написав smart contract. 

Так появился этот проект.

## Как работает escrow

### Создание сделки

Sender указывает:

- адрес Receiver
- токен, который он хочет отправить
- количество токена
- токен, который он хочет получить
- количество токена, которое хочет получить

После создания сделки:

1. создаётся Holder PDA
2. создаётся token account, которым управляет Holder PDA
3. токены Sender переводятся в escrow
4. условия сделки сохраняются в Holder account

### Принятие сделки

Receiver может загрузить сделку по адресу Sender.

При принятии сделки программа атомарно:

1. переводит токены Receiver → Sender
2. переводит токены из escrow → Receiver
3. закрывает escrow token account
4. закрывает Holder PDA

Таким образом, либо выполняется весь обмен целиком, либо транзакция откатывается.

### Отклонение сделки

Если Receiver отклоняет сделку:

1. токены из escrow возвращаются Sender
2. escrow token account закрывается
3. Holder PDA закрывается
